🔒 Why can't staff use this public URL on their phones?

Every request to the attendance API requires the secret DeviceToken in the HTTP headers. Because only authorized Branch Managers can issue this token via the 6-digit code, personal mobile phones receive 401 Unauthorized.

🏢 Why can't staff from other gyms check in here?

The backend cross-references the employee's UserGymAccess with the terminal's registered branch. If a Zamalek employee scans at Downtown, the API rejects with 403 Forbidden.
