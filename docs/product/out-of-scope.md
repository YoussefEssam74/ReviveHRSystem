# Out of Scope

The following are **NOT part of the MVP**. Do not build, suggest, or implement any of these unless explicitly requested by the project owner.

## Explicitly Excluded

### Payroll
- Full payroll calculation engine (tax, social insurance, deductions rules engine)
- Bank integration / salary disbursement
- Tax reporting
- Payroll compliance automation

### Performance & Evaluations
- Advanced performance evaluation workflows
- 360-degree feedback
- Goal setting and OKR tracking
- Performance improvement plans

### Analytics
- Advanced BI dashboards
- Predictive analytics
- AI-powered insights
- Custom report builder

### Integrations
- Multiple biometric hardware vendor implementations (support one vendor first)
- Google Forms integration (design the boundary, don't implement)
- Email / SMS notification channels (in-app only for MVP)
- Calendar integration (Google/Outlook)
- Accounting software integration
- Government/compliance integrations

### Automation
- Complex end-of-service automation beyond guided wizard
- Large-scale workflow designer / rule engine
- Automated payroll calculation rules
- Automated leave balance management

### Recruitment
- Advanced recruitment analytics (conversion funnels, time-to-hire)
- AI resume screening
- Candidate ranking/scoring
- Interview scheduling integration

### Platform
- Multi-company SaaS (this is single-tenant for Revive Solutions)
- Mobile native app (web responsive is sufficient for MVP)
- Offline mode
- Real-time chat / messaging between users
- Learning Management System (LMS)
- Employee engagement surveys
- Benefits management

### Data
- Data export to external systems
- Data migration from legacy systems (beyond CSV bulk import)
- Advanced audit log search / compliance reporting

## Rule

> **If it isn't listed in [mvp.md](mvp.md) or [features.md](features.md), don't build it.**
>
> If you believe a feature would benefit the system, document it as a suggestion in a separate file — do NOT implement it.
